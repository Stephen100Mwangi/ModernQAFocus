# ModernQAFocus

A hands-on 24-week journey to learn modern test automation and quality engineering.

## Goal

Build an end-to-end automation solution for a fictional online reservation/home-buying application and learn how quality fits into the entire software delivery lifecycle.

By the end of this roadmap, I should be able to:

- Design test strategies
- Build API automation frameworks
- Build UI automation frameworks
- Implement CI/CD pipelines
- Generate and publish reports
- Validate database data
- Run tests in Docker
- Apply quality engineering principles

## Capstone Project

### Application Features

- User Registration
- Login
- Search Communities/Homes
- Save Favorites
- Schedule Tours/Reservations
- View Reservation History

### Technology Stack

- C#, Javascript, Typescript
- Playwright
- RestSharp
- SQL Server
- Git & GitHub
- Azure DevOps
- Docker
- Allure Reporting
- GitHub Actiona

## Learning Roadmap

| Month | Focus |
|---------|---------|
| 1 | Testing Fundamentals, Test Design, Git, JS Foundations |
| 2 | API Testing with Postman and RestSharp |
| 3 | Playwright UI Automation |
| 4 | Framework Architecture and Engineering |
| 5 | Reporting and CI/CD Pipelines |
| 6 | Docker, Database Validation, and Final Project |
